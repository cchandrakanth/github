# Automation Test Fixes

One entry per stabilized failing/flaky automated test, written by the `test-fixer` subagent using `TEMPLATE.md`. Read this folder **before** touching a failing or flaky test — the flake pattern may already be documented.

Quarantined or skipped tests are recorded honestly (`fix_type: workaround`) so the debt stays visible.

Entry naming: `YYYY-MM-DD-short-slug.md`.
