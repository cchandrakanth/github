# Fix History

One entry per non-trivial bug fix, written by the `bug-fixer` subagent using `TEMPLATE.md`. Read this folder (grep by error message, file path, or tags) **before** debugging — the bug may have been seen before.

Every entry is also linked from the owning spec's `## Bug Fixes` table. Workarounds and reverts are recorded honestly with `fix_type: workaround` / `revert`.

Entry naming: `YYYY-MM-DD-short-slug.md`.
